# Delivery Roadmap

1. **Foundation (this release):** workspace, API/UI shell, dummy data, Oracle DDL/seed, core dashboard APIs, baseline tests and containers.
2. **Oracle validation:** run schema and seed on target Oracle release; query plans, integration tests, pool/failover.
3. **Identity and authorization:** enterprise identity, persisted refresh-token revocation, complete user/role/permission administration and audit.
4. **Analytics and alerts:** business-validated period comparisons, scheduled thresholds, configurable alert lifecycle and notification delivery.
5. **Reporting:** CSV/XLSX/PDF generation, scheduled delivery and access controls.
6. **Production readiness:** accessibility, load/security testing, backup restore, observability, compliance sign-off and cloud release automation.

Each phase needs acceptance criteria, deployment approval, test evidence, and updated operational runbooks.
